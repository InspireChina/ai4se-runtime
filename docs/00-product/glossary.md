# Glossary · 名词统一

| 术语 | 含义 | 非含义 |
|------|------|--------|
| **AI Delivery Orchestrator** | AI 软件交付标准 + 八能力域可执行体系 | 一个 AI；Runtime；Claude Wrapper |
| **八能力域** | 产品一级切分（01–08）；一年内不新增第九个 | Maven 模块清单；十二阶段 |
| **Repository Intelligence** | 仓数字化：Facts / Map / 入口 / 风险面 | AI 分析；需求理解 |
| **Context Engineering** | 有限 Token 下最大有效信息 → Context Package | 「写得好的 Prompt」；知识中枢 |
| **Delivery Orchestration** | Workflow（阶段）+ Control（启停/批/回环） | 模型自由 ReAct；拼包细节 |
| **Workflow** | Analysis→Plan→Dev→Verify→Review→Deliver | 控制策略本身 |
| **Control** | 继续/停/批/回环/Resume 决定 | Context 裁剪策略 |
| **AI Execution** | 模型/工具 Adapter | Worker；业务流程；业务知识 |
| **Verification** | 调用客户验证面 + Defect Package | 自建测试云；Development 自评 |
| **Knowledge Lifecycle** | 客户仓知识增删改汰/索引/晋升 | 生产洞察；Repo Scan |
| **Runtime Foundation** | Task/Artifact/Checkpoint/Trace/Worker/Decision | 产品增长面 |
| **Infrastructure** | Config/日志/启动/打包 | 业务能力垃圾桶（旧称 Platform） |
| **Context Package** | Builder 装好的结构化输入 | 整仓 dump |
| **Context Contract** | 阶段 Input(P1/P2/禁止)+Output+Stop/FAIL | 单次 Prompt 草稿 |
| **Rule / Skill** | 必须遵守 / 推荐做法（02 材料，非一级域） | 二者混用；一级能力 |
| **Worker** | Runtime 统一调用端口 | AI Execution；某家模型本身 |
